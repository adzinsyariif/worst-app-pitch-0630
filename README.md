A one-sentence pitch of the worst app idea imaginable, written for the
make.fun bounty "The Worst App Idea Ever Pitched".

`main.py` (Python 3, standard library only, no network) deterministically
writes a single sentence of at most 240 characters to `/output/entry.txt`.
Running it twice produces byte-identical output.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
